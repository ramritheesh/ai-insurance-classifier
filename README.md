# 📖 Overview

**InsurAI Classifier** is an AI-powered web application designed to simplify the processing of insurance documents. Using Google's **Gemini API**, the application intelligently analyzes uploaded insurance documents and classifies them into relevant categories, making document handling faster, more accurate, and user-friendly.

The project demonstrates the integration of modern frontend technologies with Generative AI to build practical, real-world applications.

# 🚀 Getting Started

## Prerequisites

- Node.js (v18 or later)
- npm
- Google Gemini API Key

---

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/insurai-classifier.git
```

Navigate to the project directory

```bash
cd insurai-classifier
```

Install dependencies

```bash
npm install
```

---

# 🔑 Configure Environment Variables

Create a file named

```
.env.local
```

Add your Gemini API key

```env
GEMINI_API_KEY=YOUR_API_KEY
```

> Never commit your API key to GitHub.

---

# ▶️ Run the Application

Start the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:5173
```
